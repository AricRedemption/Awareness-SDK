# F-063 · 召回首跳纯前插、默认关

- **状态**: Accepted
- **日期**: 2026-09-06

## 背景

P2-0 要在 `unifiedCascadeSearch`（全仓最热的检索路径，且有 LongMemEval 非回归门禁）前接入参数化精确召回。两种做法：改写级联内部逻辑，或在前面加一个可选 stage。

## 决策

纯前插（pure prepend）：首跳命中则短路返回，未命中/无快照/broker 不可达/任何异常则原样落入既有级联。开关 `opts.parametricFirstHop` 默认关；关闭态与改动前**逐位一致**（回归测试锁死）。E5/SQLite 通道、RRF、预算分层一行不动。

## 后果

- 非回归风险最小化：门禁期内（pending）热路径扰动为零。
- 代价是参数化命中要在结果里另立形状（`parametric_binding` 类型），不走级联的融合排序——可接受，因为精确绑定的排序语义本来就不同。
- 移除该 stage 只需删一个 if 块（可逆性）。
