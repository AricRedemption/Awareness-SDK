# F-065 · 事件钩子双开关独立、默认 False

- **状态**: Accepted
- **日期**: 2026-09-06

## 背景

P2-1 的三个钩子（record 后写参数层 / 冲突取代执行 / 会话结束快照）依赖 M1 的 consolidation_policy——该 policy 尚未合并。固化策略属于 M1 的决策域，本仓若默认开启，等于在策略缺席时替 M1 做固化决策。

## 决策

`consolidation_write` 与 `conflict_forget` 两个开关**相互独立**（各自控制写路径与冲突路径，便于单独灰度），均默认 False。会话结束快照跟随 consolidation_write（不做第三个开关——快照是写的自然收尾，拆开只会造出"写了不快照"的中间态）。

## 后果

- M1 policy 合并前，钩子代码不产生任何副作用（测试锁死双关零副作用）。
- 两个开关独立带来测试矩阵 2×2=4 种组合，全部覆盖。
- 缺点：用户要开两个开关才得到完整行为——文档须写明推荐组合。
