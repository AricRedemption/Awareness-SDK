# F-061 · 依赖方向 SDK→M1 单向，只经 memory_broker 包

- **状态**: Accepted
- **日期**: 2026-09-06

## 背景

本仓（产品分发仓）需要 M1（记忆机制研究仓）的参数化记忆能力。两仓职责不同：M1 演进快、接口不稳定；本仓面向用户、要求稳定。若依赖是双向的或直连源码，任一仓的内部重构都会打断另一仓。

## 决策

依赖方向单向：SDK → M1。调用只经 `mt_lnn.memory_broker` 包（M1 的契约面），禁止 import M1 源码模块（如 `mt_lnn.parametric_memory`）。违规即 revert（GOVERNANCE.md §1）。

## 后果

- M1 内部可以自由重构，只要 broker 契约不变。
- broker 包必须先在 M1 合并，本仓参数化功能才能联调——等待期用 mock 测试覆盖（见 F-062）。
- 若未来需要 M1 之外的能力，新增契约包而不是开洞。
